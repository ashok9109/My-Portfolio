# Personal Portfolio Website

A responsive personal portfolio website designed and developed to showcase projects, skills, and professional information. The website focuses on clean UI, smooth user experience, and cross-device compatibility.

---

## 🚀 Features

- Responsive design for mobile, tablet, and desktop devices
- Clean and modern user interface
- Interactive functionality using JavaScript
- Projects showcase section
- About, Skills, and Contact sections
- Optimized performance

---

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript  
**Tools:** Git, GitHub, VS Code
